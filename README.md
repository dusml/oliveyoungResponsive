# OliveYoung Responsive

올리브영의 브랜드와 상품 콘텐츠를 활용해 구성한 반응형 웹 페이지입니다. HTML, CSS, JavaScript와 jQuery로 메인 화면과 메뉴, 배너 슬라이드, 카테고리별 상품 탭을 구현했습니다.

## 주요 기능

- **반응형 레이아웃**: 화면 너비에 맞춰 메뉴, 상품 그리드, 콘텐츠 배치를 조정합니다.
- **헤더 인터랙션**: 스크롤 방향에 따른 헤더 표시 변화와 PC 메뉴의 마우스 오버 서브메뉴를 구현했습니다.
- **모바일 메뉴**: 햄버거 버튼으로 사이드 메뉴를 열고 닫으며, 하위 메뉴를 펼칠 수 있습니다.
- **메인 배너**: 4개의 배너가 2.5초 간격으로 자동 전환되며, 이전·다음 버튼이 배치되어 있습니다.
- **베스트 상품 탭**: 스킨케어, 마스크팩, 클렌징, 선케어 탭을 선택하면 해당 상품 목록을 표시합니다.
- **에디터 추천 콘텐츠**: 이미지와 설명으로 추천 상품을 소개합니다.

## 사용 기술

| 기술 | 용도 |
| --- | --- |
| HTML5 | 페이지 구조 및 콘텐츠 |
| CSS3 | Flexbox, Grid, 미디어 쿼리, CSS 변수를 활용한 스타일링 |
| JavaScript | 스크롤 이벤트, 메뉴 제어, 배너 전환, 상품 탭 전환 |
| jQuery 3.7.1 | 모바일 하위 메뉴 토글 |
| Google Fonts | Noto Sans KR 웹 폰트 |

## 폴더 구조

```text
oliveyoungResponsive/
├── index.html          # 메인 페이지
├── README.md           # 프로젝트 소개
├── css/
│   ├── reset.css       # 브라우저 기본 스타일 초기화
│   ├── main.css        # 메인 페이지 및 반응형 스타일
│   └── best.css        # BEST 서브페이지용 스타일 (메인에서 미사용)
├── script/
│   └── main.js         # 메뉴, 스크롤, 슬라이드, 탭 동작
└── img/
    ├── fa.png          # 파비콘
    ├── main/           # 메인 배너, 상품, 로고, 아이콘 이미지
    └── subbest/        # BEST 서브페이지용 이미지
```

## 실행 방법

별도의 패키지 설치나 빌드 과정 없이 실행할 수 있습니다.

1. 프로젝트 폴더를 다운로드하거나 복제합니다.
2. `index.html`을 웹 브라우저로 엽니다.
3. 브라우저 너비를 조절하거나 개발자 도구의 기기 모드로 반응형 화면을 확인합니다.

VS Code의 Live Server 확장을 사용하는 경우 `index.html`에서 **Open with Live Server**를 선택해도 됩니다.

jQuery와 웹 폰트는 외부 CDN에서 불러오므로 정상적인 로딩을 위해 인터넷 연결이 필요합니다.

## 반응형 구성

`css/main.css`에 아래 화면 너비를 기준으로 미디어 쿼리가 정의되어 있습니다.

```text
1270px / 1070px / 826px / 769px / 610px / 401px
```

화면 크기에 따라 헤더와 내비게이션, 배너, 상품 목록, 에디터 추천 영역, 푸터의 배치와 크기를 조정합니다. 상품 그리드는 화면 너비에 따라 4열에서 2열로 변경됩니다.

## 현재 구현 범위 및 개선 사항

- 현재 폴더에는 `index.html`만 있으며, BEST 메뉴와 MORE 링크가 가리키는 `bestsub.html`은 포함되어 있지 않습니다.
- 검색, 로그인, 회원가입, 장바구니, 상품 상세 이동 등은 화면 요소 중심으로 구성되어 있으며 실제 서비스 기능이나 백엔드와 연결되어 있지 않습니다.
- 배너의 이전 버튼은 인덱스 조건과 이동 방향을 수정해야 정상적인 이전 슬라이드 전환이 가능합니다.
- 일부 링크는 `#`으로 설정되어 있어 실제 목적지 연결이 필요합니다.
